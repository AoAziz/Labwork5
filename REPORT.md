## 1. Цель работы

Разработать учебный прототип информационной системы Smart Campus: веб-панель администратора для контроля аудиторий, IoT-устройств, энергопотребления и заявок, с модулем интеллектуального обнаружения аномалий. Закрепить навыки HTML, CSS, JavaScript, работы с localStorage, Chart.js, Git и GitHub Pages.

## 3. Архитектура

Проект разделён на HTML-страницы, один файл стилей и JS-модули:

- `data.js` — исходные тестовые данные (14 помещений, 24 устройства, 5 заявок);
- `storage.js` — `saveData`, `loadData`, `initData`, `resetData`;
- `ai.js` — пороги, z-score, обнаружение аномалий, рекомендации, уведомления;
- `common.js` — sidebar/topbar, тема, уведомления, симуляция датчиков, обёртка Chart.js;
- `dashboard.js`, `rooms.js`, `devices.js`, `incidents.js`, `analytics.js`, `settings.js`, `login.js` — логика страниц.

Поток данных: `data.js` → (первый запуск) → localStorage → страницы читают и записывают данные через `storage.js`; страницы обновляются по событию `campus:update`.

## 4. Реализованные модули

1. Login (роли Administrator / Engineer / Operator, валидация формы).
2. Dashboard (6 KPI, 3 графика, уведомления, сводка AI).
3. Rooms (14 помещений, поиск, фильтры).
4. Devices (24 устройства, фильтры, переключение статуса).
5. Incidents (CRUD, подтверждение удаления, ограничение для Operator).
6. Analytics (аномалии, причина, риск, рекомендация, создание заявки).
7. Settings (тема, параметры кампуса, сброс данных).

## 5. AI Analytics

- **Пороги:** температура 18–27 / 28–31 / ≥32 °C; CO₂ <1000 / 1000–1499 / ≥1500 ppm; энергия +30% / +60% к базовой линии.
- **Z-score:** `z = |x − mean| / σ`, аномалия при `z` выше порога (по умолчанию 2.5).
- **Рекомендации:** набор правил по состоянию помещения.

Это статистика и правила, а не генеративный AI: внешние API не используются, секретные ключи в браузере не хранятся.

## 8. Ответы на контрольные вопросы

1. **Smart Campus** — кампус, где датчики и ПО собирают данные о помещениях и оборудовании для управления ими.
2. **Данные IoT** — температура, CO₂, освещённость, потребление электроэнергии, доступ, видео, состояние оборудования.
3. **CRUD** — Create, Read, Update, Delete: создание, чтение, изменение, удаление записей.
4. **localStorage** — хранилище браузера «ключ–значение», данные сохраняются между сессиями.
5. **JSON** — текстовый формат обмена данными (объекты и массивы).
6. **Chart.js** — библиотека для построения графиков на canvas.
7. **Аномалия** — значение, заметно отличающееся от обычного поведения данных.
8. **Z-score** — число стандартных отклонений между значением и средним.
9. **Rule-based ≠ генеративный AI** — правила выполняют заранее заданные условия, а генеративная модель создаёт новый текст на основе обучения.
10. **API-ключ** — любой пользователь увидит код браузера, поэтому ключ нужно хранить на backend.
11. **Git** — система контроля версий, хранит историю изменений.
12. **GitHub Pages** — бесплатный хостинг статических сайтов из репозитория GitHub.
