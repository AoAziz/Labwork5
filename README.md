# Smart Campus AI

Интеллектуальная веб-платформа управления инфраструктурой учебного заведения (лабораторный проект).
Административный dashboard для контроля аудиторий, IoT-устройств, энергопотребления и заявок с модулем AI-аналитики (статистическое обнаружение аномалий и рекомендации).

**Демо:** `https://ВАШ_ЛОГИН.github.io/smart-campus-ai/`

## Возможности

- **Login** — учебная форма входа, роли Administrator / Engineer / Operator (имитация, не настоящая защита; Operator не может удалять заявки).
- **Dashboard** — 6 KPI, 3 графика Chart.js (энергия по корпусам, тренд температуры, статус устройств), уведомления, сводка AI.
- **Rooms** — 14 помещений, поиск, фильтры по статусу и корпусу, рекомендация AI для каждой строки.
- **Devices** — 24 IoT-устройства, поиск, фильтры (статус, тип, корпус), переключение online/offline.
- **Incidents** — полный CRUD заявок: создание, редактирование, смена статуса, удаление с подтверждением.
- **Analytics** — список аномалий (причина, риск, метод, рекомендация), 3 графика, кнопка «Создать заявку».
- **Settings** — светлая/тёмная тема, название кампуса, порог z-score, автообновление, сброс данных.
- **Notifications** — высокий CO₂, перегрев, offline-устройства, перерасход энергии.
- Данные хранятся в **localStorage**, показания датчиков имитируются JavaScript.
- Адаптивная вёрстка (1920 / 1366 / 768 / 390 px).

## Как запустить

Откройте папку в VS Code и запустите **Live Server** (или любой локальный сервер, например `python -m http.server`), затем откройте `index.html`.
Для графиков нужен интернет (Chart.js подключается через CDN).

## Как работает AI Analytics

Модуль не использует внешние API и не является генеративным ИИ. Он состоит из трёх частей:

1. **Пороги** — температура: 18–27 °C норма, 28–31 внимание, ≥32 критично; CO₂: <1000 норма, 1000–1499 внимание, ≥1500 критично; энергия: +30% / +60% к базовой линии помещения.
2. **Z-score** — текущее значение сравнивается со средним по последним показаниям помещения. Если отклонение больше заданного порога (по умолчанию 2.5σ), значение считается аномалией. Для температуры, CO₂ и энергии введён нижний предел σ, чтобы не реагировать на шум.
3. **Recommendation Engine** — правила, которые превращают состояние помещения в понятную рекомендацию (например, «людей нет, но энергопотребление высокое»).

> Секретные API-ключи нельзя хранить в браузерном JavaScript. Для настоящего AI API нужен backend или serverless-функция.
